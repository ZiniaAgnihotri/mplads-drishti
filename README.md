# 🏛️ MPLADS-Drishti (एमपिलाड्स दृष्टि)

**AI Audit & Analytics Platform for MPLAD Scheme**

🏆 Smart India Hackathon 2026 — Problem ID: 26102  
📌 Ministry: MoSPI (Ministry of Statistics & Programme Implementation)

## 🌟 Features
- 🌐 Full bilingual support (English ⇄ हिन्दी)
- 🏛️ Role-based dashboards (MoSPI / MP / District Authority)
- 🚨 AI Anomaly Detection Engine (Duplicate billing, Ghost projects, Cost inflation, Unspent funds)
- 🗺️ Geospatial project tracker with satellite audit
- 📊 Real-time fund utilization analytics
- 📥 Forensic audit report generator
- 📢 Whistleblower grievance portal

## 🛠️ Tech Stack
- HTML5 + Tailwind CSS
- Chart.js (analytics)
- Leaflet.js (geospatial maps)
- Lucide Icons
- Firebase-ready architecture
